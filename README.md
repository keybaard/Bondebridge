# Poengblokka

Poengblokk for bondebridge og spar dame. Én telefon fører poeng, de andre scanner QR-koden og ser stillingen live.

- Poeng: klart = 10 + antall stikk, bom = 0 (kan endres i oppsettet)
- Live-tavle via [ntfy.sh](https://ntfy.sh) – ingen konto nødvendig
- Alt er én fil: `index.html`

- Spar dame: hjerter, spar dame, ruter knekt, skyte månen, poenggrense eller fast antall runder – alt kan stilles inn
